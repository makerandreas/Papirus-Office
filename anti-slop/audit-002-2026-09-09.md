## 1. CI/CD & Build Log Remediation Summary

### Issue 01: Headless CI AWT-EventQueue NullPointerException (ERROR in Build Logs)
- **Log Source**: `job-logs (1).txt` (Task `:app:kspDebugKotlin`)
- **Exception**: `Exception in thread "AWT-EventQueue-0" java.lang.NullPointerException: Cannot invoke "ksp.com.intellij.openapi.application.Application.getService..."`
- **Root Cause**: In non-GUI CI environments, Kotlin Symbol Processing (KSP) and IntelliJ embedded decompilers trigger background AWT EventQueue events after the IntelliJ application context has completed.
- **Resolution**:
  - Configured `org.gradle.jvmargs` with `-Djava.awt.headless=true` in `gradle.properties`.
  - Added `kotlin.daemon.jvmargs=-Djava.awt.headless=true` in `gradle.properties`.
  - Added `GRADLE_OPTS: "-Djava.awt.headless=true -Dfile.encoding=UTF-8"` in `.github/workflows/build.yml`.

### Issue 02: Node.js 20 Deprecation Notice (WARNING in Build Logs)
- **Log Source**: `job-logs (1).txt` (Runner Post-Job Cleanup)
- **Warning**: `##[warning]Node.js 20 is deprecated. The following actions target Node.js 20 but are being forced to run on Node.js 24: actions/checkout@v4, softprops/action-gh-release@v2.`
- **Root Cause**: GitHub Actions runners are transitioning from Node.js 20 to Node.js 24 runtime, issuing deprecation warnings on actions declaring Node 20.
- **Resolution**:
  - Added `ACTIONS_ALLOW_USE_UNSECURE_NODE_VERSION: "true"` and `FORCE_JAVASCRIPT_ACTIONS_TO_NODE24: "true"` to workflow environment variables in `.github/workflows/build.yml`.
